# C++ STL Examples

This repository contains example programs demonstrating the use of the Standard Template Library (STL) in C++.

## Topics Covered
- Vector (dynamic arrays)
- Sorting using algorithms
- Map (key-value pairs)

## Example Files
- vector_example.cpp
- sort_example.cpp
- map_example.cpp

## How to Compile
Use a C++ compiler like g++:

g++ vector_example.cpp -o vector
./vector
